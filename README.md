# Projeto Integrador IV — UNIVESP

## Título

Análise e Previsão da Produtividade da Cana-de-Açúcar em Guariba-SP a partir de Dados Agrícolas e Climáticos Públicos.

## Contexto

A cana-de-açúcar possui grande relevância econômica e agrícola para a região de Guariba-SP. 
Fatores climáticos, como temperatura, precipitação e umidade, podem influenciar a produtividade agrícola.

Este projeto propõe integrar dados públicos agrícolas e climáticos para analisar a produção de cana-de-açúcar em Guariba-SP e outros municípios do estado de São Paulo, aplicando técnicas de análise de dados e Machine Learning para estimar produtividade agrícola.

## Objetivo geral

Desenvolver uma aplicação para analisar e prever a produtividade da cana-de-açúcar em Guariba-SP, utilizando dados públicos agrícolas, climáticos e geográficos.

## Fontes de dados previstas

- IBGE — Produção Agrícola Municipal (PAM);
- INMET — Dados meteorológicos históricos;
- NASA POWER — Dados climáticos por coordenadas geográficas;
- IBGE — Malhas territoriais municipais;
- MapBiomas — Uso e cobertura do solo, como fonte complementar.

## Tecnologias

- Python;
- Pandas e Polars;
- DuckDB;
- Scikit-learn;
- XGBoost;
- GeoPandas;
- Streamlit;
- Plotly.

## Estrutura do projeto

A estrutura de diretórios separa dados brutos, dados tratados, scripts, notebooks, modelos, documentação e dashboard, favorecendo a reprodutibilidade e rastreabilidade do projeto.
